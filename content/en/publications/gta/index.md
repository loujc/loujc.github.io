  GTA is a GPU-accelerated, design-rule-aware track-assignment framework for bridging global and detailed routing. A lightweight lookup table enables efficient conflict detection while preserving routing quality. Compared with TritonRoute-WXL in the reported experiments, GTA achieves a 20x runtime speedup and reduces peak CPU memory by 25% while maintaining competitive detailed-routing quality.
