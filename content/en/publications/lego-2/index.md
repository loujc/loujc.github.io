abstract: >-
  Existing LLM agents address isolated EDA tasks through project-specific workflows, limiting method transfer and cross-case experience reuse. LEGO 2.0 coordinates reusable circuit skills through a stage-structured agent team and an Agent State Gateway, automatically builds skills from open-source projects, and organizes cross-case memory with a three-layer Agent Memory System. It also packages back-end parameter search as a governed tuning skill that separates agent direction selection from validation and tool execution. On 262 CVDP front-end RTL tasks, LEGO 2.0 achieves 201 passes (76.7%) with 58.9% fewer tokens than MAGE; memory-assisted recovery raises the combined pass rate to 93.5%. On three commercial ARM IP designs, it improves placement WNS by up to 18.2% and TNS by up to 26.6%, with full-flow Innovus gains reaching 57.9% in WNS and 86.5% in TNS.
